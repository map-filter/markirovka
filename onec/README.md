# Внешняя обработка 1С «Маркировка за день: коды маркировки»

Исходники внешней обработки для 1С:Бухгалтерии 3.0 для Казахстана и 1С:УНФ для Казахстана (платформа 8.3.10 и новее, управляемые формы). Обработка берёт коды Data Matrix и их статусы из сервиса через REST API и:

- показывает заказы кодов и коды по выбранному заказу или GTIN;
- обновляет статусы кодов (получен, напечатан, нанесён, в обороте, аннулирован);
- записывает коды в табличную часть документа 1С (реализация, поступление, отчёт производства), если в документе есть табличная часть «КодыМаркировки» или «ШтрихкодыУпаковок»;
- сохраняет коды в текстовый файл по одному в строке для загрузки типовой командой «Загрузить коды из файла».

Символ GS (0x1D) внутри кода не теряется: сервис отдаёт код в поле `code_base64`, обработка декодирует его через `Base64Значение`.

## Состав

```
МаркировкаЗаДень/
  Ext/ObjectModule.bsl                 модуль объекта: HTTP-запросы, разбор JSON, запись в документ
  Forms/Форма/Ext/Form/Module.bsl      модуль формы
  Forms/Форма/Описание.txt             реквизиты, команды и элементы формы
```

## Как собрать .epf

1. Конфигуратор: Файл, Новый, Внешняя обработка. Имя `МаркировкаЗаДень`, синоним «Маркировка за день: коды маркировки».
2. Открыть модуль объекта и вставить `Ext/ObjectModule.bsl`.
3. Добавить форму «Форма» (основная), создать реквизиты, команды и элементы по `Описание.txt`, вставить модуль формы.
4. Сохранить как `МаркировкаЗаДень.epf`. Подключить в «Дополнительные отчеты и обработки» (функция `СведенияОВнешнейОбработке` уже есть) или открыть через Файл, Открыть.

## Настройка

- Адрес сервиса: адрес кабинета, например `http://127.0.0.1:8301` для локального запуска.
- Токен интеграции: кабинет, Настройки, «Токен для 1С», кнопка «Выпустить». Токен показывается один раз.

## Методы API, которые использует обработка

| Метод | Назначение |
|---|---|
| `GET /api/integration/v1/orders` | список заказов кодов |
| `GET /api/integration/v1/codes?format=json&order=З-000001` | коды заказа (также `gtin`, `status`, `updated_since`, `format=csv`) |
| `POST /api/integration/v1/codes/statuses` | статусы по списку кодов `{"codes": [...]}` |

Авторизация: заголовок `Authorization: Bearer <токен интеграции>`.

## Ограничения

- Имена табличных частей и реквизитов в типовых конфигурациях КЗ разных релизов отличаются. Обработка ищет их по списку вариантов (`КодыМаркировки`, `ШтрихкодыУпаковок`; `КодМаркировки`, `ЗначениеШтрихкода`), при отсутствии предлагает выгрузку в файл. На конкретной базе это нужно проверить и при необходимости дописать имя в `ЗаписатьКодыВДокумент`.
- В базовых версиях 1С внешние обработки ограничены: обработку нужно встроить в конфигурацию или использовать выгрузку CSV из кабинета.
- `.epf` в репозитории не хранится: собирается из исходников по шагам выше.
