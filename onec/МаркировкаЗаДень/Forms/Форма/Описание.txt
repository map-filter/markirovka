Форма «Форма» (управляемая, основная форма обработки)

Реквизиты формы
  Объект           ВнешняяОбработкаОбъект.МаркировкаЗаДень (основной)
  АдресСервиса     Строка(200)
  Токен            Строка(100), режим пароля
  НомерЗаказа      Строка(20)
  GTIN             Строка(14)
  Документ         ДокументСсылка (составной тип: РеализацияТоваровУслуг, ПоступлениеТоваровУслуг,
                   ОтчетПроизводстваЗаСмену или любой документ с табличной частью КодыМаркировки)
  Номенклатура     СправочникСсылка.Номенклатура
  Заказы           ТаблицаЗначений
    Номер          Строка(20)
    GTIN           Строка(14)
    Товар          Строка(500)
    Количество     Число(10,0)
    Статус         Строка(20)
  Коды             ТаблицаЗначений
    Код            Строка (неограниченная), хранит код с символом GS (0x1D)
    КодЧитаемый    Строка (неограниченная)
    GTIN           Строка(14)
    Серийный       Строка(32)
    Статус         Строка(20)
    СтатусПредставление Строка(30)
    Товар          Строка(500)
    Заказ          Строка(20)

Команды формы
  ЗагрузитьЗаказы    «Загрузить заказы»           действие ЗагрузитьЗаказы
  ПолучитьКоды       «Получить коды»              действие ПолучитьКоды, кнопка по умолчанию
  ОбновитьСтатусы    «Обновить статусы»           действие ОбновитьСтатусы
  ЗаписатьВДокумент  «Записать в документ»        действие ЗаписатьВДокумент
  СохранитьВФайл     «Сохранить коды в файл»      действие СохранитьВФайл

Элементы формы (сверху вниз)
  ГруппаНастройки (обычная группа, горизонтальная, заголовок «Подключение к сервису»)
    АдресСервиса   поле ввода, ПриИзменении = АдресСервисаПриИзменении
    Токен          поле ввода, режим пароля, ПриИзменении = ТокенПриИзменении
  ГруппаОтбор (горизонтальная)
    НомерЗаказа    поле ввода
    GTIN           поле ввода
    КнопкаЗагрузитьЗаказы, КнопкаПолучитьКоды
  Заказы           таблица, только просмотр, высота 6 строк, Выбор = ЗаказыВыбор
    колонки Номер, Товар, GTIN, Количество, Статус
  Коды             таблица, только просмотр
    колонки КодЧитаемый (ширина 40), Товар, Статус (СтатусПредставление), Заказ
    командная панель: ОбновитьСтатусы, СохранитьВФайл
  ГруппаДокумент (горизонтальная, заголовок «Запись в документ 1С»)
    Документ       поле ввода
    Номенклатура   поле ввода
    КнопкаЗаписатьВДокумент
